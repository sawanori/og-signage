## 採用しなかった指摘

| 指摘 | 指摘元 | 理由 |
|---|---|---|
| 端末 API が 404 を返すとトークンを総当たりで探せる | Gem-B | トークンは 256 ビットの乱数で、総当たりは現実的でない。ただしトークンを URL に載せない変更（#19）は別の理由で採用した |
| R2 の中継をやめ、署名付き URL で直接取得させる | Gem-B, Gem-A | R2 のアクセスキーをアプリに持たせない方針（TECH_STACK 21 節）と衝突する。Worker でストリームのまま中継すればメモリにためないため、task_002 で 500MB の中継を実測して判断する |
| Heartbeat を 30 秒、OFFLINE 判定を 2 分に短縮する | Gem-B | 要件定義書 25 節の値（60 秒 / 5 分）で完成条件を満たせる。表示異常は #9 で別に検知する |
| フォントはバンドルに入れず Pi の OS フォントを使う | Gem-B | 管理画面のプレビューと Pi で見た目がずれる。サブセット化した WOFF2 を同梱する |
| 30 秒反映の要件を 45 秒に緩める | Gem-B | ポーリング短縮（#7）で要件どおり満たせる |
